How I work

From Figma handoff to launch

I built my own AI-assisted delivery system with Claude Code and the Webflow MCP: a project starter, a development standards guide and 12 stage-based workflows. It makes every build faster and more consistent, without cutting corners on quality.

  1. 01

    Setup & tokens

    Project kickoff, Figma review and design tokens mapped to Webflow Variables for colour, type and spacing.

  2. 02

    Build

    Pixel-accurate pages on a Client-First class system, with reusable components, props and variants.

  3. 03

    Responsive

    Every breakpoint designed for, not patched. Tested across browsers and real devices.

  4. 04

    CMS

    Collections clients can manage themselves: blogs, case studies, filters, location pages and FAQs.

  5. 05

    Interactions

    Webflow Interactions and GSAP (ScrollTrigger, SplitText), Lottie, Three.js and Canvas 2D when the brand calls for it.

  6. 06

    SEO, QA & launch

    Meta titles, Open Graph, JSON-LD schema, alt text, image optimisation, visual QA and a clean launch.
