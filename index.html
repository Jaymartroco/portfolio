02 / How I work

From Figma handoff to launch

I built my own delivery system with Claude Code and the Webflow MCP: a project starter, a development standards guide and 12 stage-based workflows. Faster builds, without cutting corners.

  1. 01

    Setup & tokens

    Kickoff, Figma review and design tokens mapped to Webflow Variables for colour, type and fluid spacing.

  2. 02

    Build

    Pixel-accurate pages on a Client-First class system, with reusable components, props and variants.

  3. 03

    Responsive

    Every breakpoint designed for, not patched. Fluid sizes, layout-only overrides, tested on real devices.

  4. 04

    CMS

    Collections clients can run themselves: blogs, case studies, filters, location pages and FAQs.

  5. 05

    Interactions

    Webflow Interactions and GSAP (ScrollTrigger, SplitText), plus Lottie, Three.js and Canvas when the brand calls for it.

  6. 06

    SEO, QA & launch

    Meta titles, Open Graph, JSON-LD, alt text, image optimisation, visual QA and a clean launch.
