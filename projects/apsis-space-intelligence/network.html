The intelligence network for space.

Apsis is building a network that can see objects across Earth orbit and beyond. It combines purpose-built sensors with partner spacecraft to make more of space visible, more often.

See more, more often

A single image gives you one view of an object. Multiple observations reveal how it changes over time.

Apsis's network creates repeated opportunities to observe the same object while extending coverage to understand objects we haven't seen before.

ONCE

High revisit

Multiple sensors create more opportunities to observe the same object. Repeated imagery makes changes easier to detect.

SPACE

Expanding coverage

Extend Non-Earth Imaging across more orbital regimes. Apsis is expanding from LEO towards GEO and, eventually, beyond Earth orbit.

DETAIL

High resolution

Capture detail down to 5 cm per pixel. Resolve spacecraft configuration, subsystems, deployment state, and anomalies.

kind

Ready for different sensors

Bring different sensing types into the same network. Each one adds another way to understand the space environment.

inspection

Multiple inspection approaches

Flyby

Use naturally occurring proximity opportunities to inspect objects without dedicated manoeuvres.

Rendezvous Inspection

Use compatible spacecraft to rendezvous with a target when closer, longer or more controlled inspection is required.

mission

Build coverage where it's needed

Gaps in space-based observation are inevitable. Apsis builds sensors to close them.

We place purpose-built payloads across partner spacecraft and dedicated missions. That lets the network reach new orbits, new objects, and new operating environments.
